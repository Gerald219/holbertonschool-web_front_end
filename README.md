# Web frontend coursework

Holberton School exercises in semantic HTML and CSS. The numbered files show incremental coursework rather than a single finished production website.

## What is included

| Directory | Topics |
| --- | --- |
| `html_advanced/` | Page structure, semantic sections, navigation, links, images, articles, and style-guide examples |
| `CSS_advanced/` | Selectors, typography, variables, layout, navigation styling, hover effects, and transitions |

Start with [the HTML homepage](html_advanced/index.html) or [the HTML style guide](html_advanced/styleguide.html). The homepage is an HTML exercise and has no stylesheet attached. CSS assignments are separate files in [CSS_advanced/styles](CSS_advanced/styles); later files may import earlier exercises.

## View locally

Clone the repository, then run this command from its root:

```bash
python3 -m http.server 8000
```

Open `http://127.0.0.1:8000/html_advanced/index.html`. You can also open the HTML files directly in a browser. The local server needs Python 3; it is only for previewing static coursework.

The sample Techium business and page content are part of the coursework. These files do not establish client work or a deployed commercial website.
